## How Can I Edit This Code?

There are several ways to edit your application.

**Use Your Preferred IDE**

You can work locally using your preferred IDE by cloning this repository and pushing changes.

The only requirement is having Node.js and npm installed. [Install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

- **Sign-in and business profile** — business or household details, contact information, location, hiring needs, budget, and logo.
- **Dashboard and my gigs** — hiring overview, active openings, and applicant activity.
- **Post a gig** — choose business or individual hiring, role category, title, description, area, duration, timing, pay amount and unit, openings, and immediate-start status.
- **Candidate search** — discover profiles using verification, rating, distance, availability, and work-type filters.
- **Saved candidates** — keep a shortlist for future hiring.
- **Applications and hiring history** — review candidate notes and profile details, and track past work.
- **Shift completion flow** — authorize a shift, finalize its release, and record workplace feedback and a rating.

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm install

# Step 4: Start the development server.
npm run dev
```

**Edit a File Directly on GitHub**

- Navigate to the desired file(s).
- Click the "Edit" button (pencil icon) at the top right of the file view.
- Make your changes and commit them.

## Feature areas

- Navigate to the main page of your repository.
- Click the "Code" button.
- Select the "Codespaces" tab.
- Click on "New codespace" to launch a development environment.
- Edit files directly in Codespaces and commit and push your changes.

## What Technologies Are Used?

- Candidate-to-customer messaging after an application.
- Live alerts for applications, bookings, shift updates, and verification decisions.
- Two-way post-shift reviews, with rating summaries shown on profiles.
- Document upload and review for candidate and business verification.
- A dedicated, efficient photo and logo storage flow.
- Saved gigs for candidates, alongside saved candidates for customers.
- Location-verified clock-in/out and automatic shift-pay calculations.
- Top candidate recommendations for each opening, based on skills and availability.
- Calendar export for booked shifts.
- Fully connected wallet transactions, fee goals, Fee Safe Mode, fee reminders, and direct fee payment options.
- Savings streaks, no-spend challenges, and referral rewards.
- More course content and hiring-linked micro-certifications.
